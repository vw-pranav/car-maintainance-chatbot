# Car Maintenance RAG Chatbot

A Retrieval-Augmented Generation chatbot for automobile maintenance manuals.

## Features

- PDF ingestion
- Chunking
- Embeddings
- ChromaDB
- Ollama
- LangChain
- Streamlit UI

## Tech Stack

- Python
- LangChain
- ChromaDB
- Ollama
- Streamlit

## Run

pip install -r requirements.txt

python ingest.py

streamlit run app.py
